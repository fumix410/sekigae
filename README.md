# 席替えサポート

学校の先生のための席替え支援Webアプリです。配慮事項（視力・人間関係など）を守ったランダム席替えと、手動での微調整ができます。

データはブラウザの localStorage にだけ保存され、外部には送信されません。

## 使い方

画面の左に設定（折りたたみ式）、右に座席表が常に表示されます。画面幅が狭いときは縦に並びます。

1. **名簿**：Excel（.xlsx）か CSV ファイルを読み込むか、名前を1行に1人ずつ貼り付けて登録します。1行目に「名前」「前方希望」の見出しがあれば、前方希望（「○」「1」「あり」など）も一緒に読み込みます。サンプルは `public/samples/sample-roster.xlsx`（画面の「サンプル（Excel）をダウンロード」からも取得できます）。
2. **教室の配置**：席の横・前後の数を決めます。教卓の位置は「上（生徒から見た向き）」か「下（教卓から見た向き。座席表が180°回転します）」を選べます。座席表で空いている席をタップすると使わない席になり、もう一度タップすると戻ります（生徒が座っている席は「使わない席を座席表で選ぶ」から切り替えます）。
3. **配慮条件**：条件を追加します。
   - 2人を隣にしない（斜めを含むかどうかを選べます）／2人を離す／2人を左右の隣にする／前の方の席にする／席を固定する
4. **座席表**：「席替え実行」を押します。結果はドラッグ＆ドロップ（またはクリック2回）で入れ替えられます。🔒 の席は再実行しても動きません。条件に違反している席はオレンジ色で表示されます。

座席表は「印刷」のほか、「Excel に書き出す」で .xlsx ファイル（座席表と名簿の2シート。席と席の間には上下左右とも空の行・列が入ります）にできます。書き出したファイルを「名簿」の「Excel・CSV ファイルから読み込む」で読み込むと、名簿と座席の配置が戻ります（Excel で名前を直したり、座席表シートで名前を入れ替えたりしたものも使えます。条件・席の固定は戻らないので、まるごと戻すときは「バックアップを保存」を使ってください）。

「バックアップを保存」で JSON ファイルにバックアップでき、別のPCで「バックアップから復元」すると続きから使えます。

## 開発

```sh
npm install
npm run dev     # 開発サーバー
npm test        # ユニットテスト（Vitest）。手動テストの項目は docs/テスト項目.md
npm run build   # dist/ に静的ファイルを出力（GitHub Pages などにそのまま置けます）
```

## 構成

- `src/logic/` — 席の割り当てロジック（UI に依存しない純粋関数）
  - `seating.ts`：ランダム再スタート付きのバックトラッキング。条件を満たす配置が見つからない場合は、違反の少ない配置を貪欲法で探して返す
  - `constraints.ts`：条件の判定と違反の検出
  - `geometry.ts`：座席の座標・隣接判定
  - `roster.ts`：Excel・CSV・貼り付けからの名簿の読み取り
  - `excelImport.ts`：書き出した座席表 Excel からの名簿・配置の読み戻し
- `src/state/store.tsx` — useReducer による状態管理と localStorage への保存
- `src/components/` — 各タブの画面
